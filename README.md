# Guionero — Página oficial

Sitio estático de presentación de Guionero, preparado para GitHub Pages. La portada destaca la marca “Guionero” en blanco y violeta, con los lemas en una escala más pequeña debajo.

## Contenido
- `index.html`: web completa. Las tres capturas auténticas de Script, Node y Paint están embebidas en el HTML para que sigan apareciendo incluso si solo se publica este archivo.
- `assets/guionero-script.jpg`, `assets/guionero-node.jpg`, `assets/guionero-paint.jpg`: capturas fuente usadas en la página.
- `manifest.webmanifest`, `sw.js`: soporte de instalación web y caché para navegadores compatibles.

## Publicación
Sube el contenido completo de esta carpeta a la raíz de `Emmanuel12334/Guionero-Web` y activa GitHub Pages desde `Settings → Pages`, rama `main`, carpeta `/(root)`.

## Nota
El botón de acceso abre `https://emmanuel12334.github.io/Guionero-App/`. La URL de la aplicación debe estar publicada por separado para que el botón funcione online.
